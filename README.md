# Russia ABAP

A testing project for ABAP development.

## Contents

- `Russia_ABAP.zip` — ABAP source files archive

## About

This repository is used for testing ABAP code and development workflows.

## Getting Started

1. Download or clone this repository
2. Extract `Russia_ABAP.zip` to access the ABAP source files
3. Import the files into your SAP system using SE38, SE80, or your preferred tool

## Requirements

- SAP system access (ECC, S/4HANA, or equivalent)
- SAP GUI or Eclipse ADT (ABAP Development Tools)
